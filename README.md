Snake Game 🐍

A classic Snake Game built with Python and Pygame as my first-year programming project.

Features

- Arrow-key controls
- Food generation and snake growth
- Score tracking
- High-score saving across game sessions
- Wraparound movement
- Self-collision detection
- Pause and resume (Press p) 
- Game-over screen and restart option(Press r) 

Technologies Used

- Python
- Pygame
- Git and GitHub

How to Run

1. Install Python.

2. Install Pygame using:
   
   "python -m pip install pygame"

3. Run the game:
   
   "Snake.py"

What I Learned

This project helped me practise Python programming, event handling, game logic, collision detection, file handling, and version control.
